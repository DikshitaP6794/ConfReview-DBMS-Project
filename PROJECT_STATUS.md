# Prototype status

## Implemented in this prototype
- Dashboard with counts and recent submissions
- Paper submission and search/filter
- Unique submission codes and author email uniqueness
- Paper version metadata tracking
- Reviewer directory and workload counts
- Reviewer assignment with duplicate assignment prevention
- Review scoring (1–10) and recommendation
- Editorial decisions and paper status updates
- Presentation slot creation/update
- Reports for status, track distribution, reviewer workload and paper scores
- CSV export
- SQLite foreign keys, UNIQUE, CHECK, NOT NULL and indexes

## Not implemented yet
- Real manuscript file upload/storage (version names are metadata only)
- Authentication and role-based access control
- Automatic conflict-of-interest detection
- Automated minimum-review-count enforcement before final decision
- Prevention of overlapping presentation slots across authors/rooms
- Automated tests and production deployment

These are known prototype limitations and must be described honestly in the final report.
